## Project tracker (Room)

This project is tracked in Room, which reads `TRACKER.md` from this GitHub repository.

- **When you start:** read `TRACKER.md`, especially *Next up* and *Definition of Done*, so you know where things stand and what to do.
- **Before you finish any session where something changed:**
  1. Add one line at the top of *Log*: `- YYYY-MM-DD · <your tool: Claude Code / Codex / Gemini / ChatGPT> · what changed`.
  2. Tick *Definition of Done* items only when they are actually done and verified. Add new items if the scope grew. Never delete items to make the progress bar move.
  3. Rewrite *Next up* so the next session, in any tool, can pick up straight away.
  4. Update `stage` (Idea, Planning, Design, Building, Polish, Live, Shipped, Paused) and `updated` in the front matter.
  5. Commit `TRACKER.md` together with your work, so Room sees the update.
